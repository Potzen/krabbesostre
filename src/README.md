# Rå kildebilleder

Her ligger de ubehandlede billeder, som `tools/build_images.py` beskærer,
skalerer og konverterer til WebP i `billeder/`. Se `JOBS`-listen i scriptet
for hvilke filnavne det forventer.

Denne mappe er ikke en del af selve hjemmesiden og indgår ikke i det, der
lægges op på webhosten. Kun `billeder/`-mappens output gør.
