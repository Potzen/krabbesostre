# Billeder

Alle 25 filer, som `index.html` og `nytaarskasse.html` peger på, ligger nu
her: logo, ikoner, hero-billeder, galleriet og OG-billedet til deling.

`tools/build_images.py` dækker kun en delmængde af dem (se scriptets
`JOBS`-liste). Resten er lagt direkte som færdige `.webp`/`.png`-filer.
Skal et billede skiftes ud senere, er det nemmest bare at sende den nye fil
i chatten og sige, hvilket filnavn den skal erstatte.
